# Clinic Call List

A responsive clinic call list webpage built using **HTML, CSS, and JavaScript**.

## Features

- 📱 Responsive design optimized for mobile screens
- 🔍 Live caller-name search
- ❌ Clear search button
- 📊 Dynamic call count
- 🏷️ Clear status badges: Answered, Failed, No answer
- 📭 Empty state when no callers match
- Handles missing caller names as **"Unknown caller"**
- Compact and easy-to-scan call cards

## Tech Stack

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download the repository.
2. Open `index.html` in your browser.

No backend or additional setup is required.
